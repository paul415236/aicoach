# Windows 使用說明（給完全不會寫程式的人）

這份說明會一步步帶你在 Windows 電腦上使用 Garmin AI Coach。
全部只需要「雙擊」幾個檔案，不用打任何程式。

> ⚠️ 使用前請務必先閱讀專案 README 開頭的免責聲明。本工具為非官方、個人研究用途，
> 使用第三方函式庫存取 Garmin 帳號資料，可能違反 Garmin 服務條款，風險請自行承擔。

---

## 你需要準備的東西

1. 一台 Windows 10 或 Windows 11 的電腦
2. 你的 **Garmin Connect** 帳號（Email 和密碼）
3. 一組免費的 **OpenRouter API Key**（下面第 2 步會教你拿）

---

## 第 1 步：安裝 Python（只需做一次）

程式需要 Python 才能執行。

1. 打開瀏覽器，前往 👉 <https://www.python.org/downloads/>
2. 點擊黃色的大按鈕「**Download Python**」下載安裝檔
3. 下載完成後，雙擊打開安裝檔
4. **【非常重要】** 安裝畫面最下方，請務必勾選
   ☑️ **「Add Python to PATH」**（加入 PATH）
   ![勾選 Add Python to PATH]
5. 然後點「**Install Now**」，等待安裝完成，最後按「Close」

> 💡 如果你不確定電腦是否已裝過 Python，直接做下面第 3 步也沒關係，
> 若偵測不到會跳出提示叫你回來裝。

---

## 第 2 步：取得免費的 OpenRouter API Key

這是讓 AI 幫你分析課表用的金鑰。

1. 前往 👉 <https://openrouter.ai/>
2. 點右上角登入 / 註冊（可用 Google 帳號快速登入）
3. 登入後，點選左側或個人選單裡的「**Keys**」
4. 點「**Create Key**」建立一組新的金鑰
5. 複製那串以 `sk-or-` 開頭的文字（這就是你的 API Key）

> 💡 先把它複製著，等一下第 4 步會用到。

---

## 第 3 步：安裝程式依賴套件（只需做一次）

1. 打開程式資料夾裡的 **`windows`** 子資料夾
   （下面要用到的三個 `.bat` 檔都在這個 `windows` 資料夾裡）
2. 找到 **`install.bat`**，**雙擊**它
3. 會跳出一個黑色視窗自動安裝，請耐心等待
4. 看到「**安裝完成！**」字樣後，按任意鍵關閉視窗

> ❓ 如果視窗說「偵測不到 Python」，表示第 1 步沒裝好，
> 請回第 1 步重新安裝，並記得勾選「Add Python to PATH」。

---

## 第 4 步：設定你的帳號（只需做一次）

1. 找到 **`設定帳號.bat`**，**雙擊**它
2. 依照畫面提示，依序輸入：
   - **Garmin Email**：你登入 Garmin Connect 的電子郵件
   - **Garmin 密碼**：你的 Garmin 密碼（輸入時螢幕會顯示，請注意旁邊沒有人）
   - **OpenRouter API Key**：貼上第 2 步複製的那串 `sk-or-...`
     （在黑色視窗中「按右鍵」就能貼上）
3. 看到「**設定完成！**」就好了，按任意鍵關閉

> 🔒 你的帳密只會存在你自己電腦的 `.env` 檔裡，不會上傳到任何地方。

---

## 第 5 步：啟動程式（每次使用都做這步）

1. 找到 **`start.bat`**，**雙擊**它
2. 會跳出黑色視窗，稍等幾秒，瀏覽器會**自動打開**網頁
   （若沒自動開，請自己打開瀏覽器輸入網址：`http://localhost:5000`）
3. 現在就能使用了！

> ★ 使用期間請**不要關閉那個黑色視窗**，關掉它就等於關掉程式。
> 用完後直接關閉黑色視窗即可結束程式。

---

## 開始使用：網頁上的兩個按鈕

| 按鈕 | 作用 |
|---|---|
| 🔄 同步 Garmin | 把最近 12 個月的跑步紀錄從 Garmin Connect 抓下來 |
| 🤖 AI 分析 | 打開設定視窗，產生下週的訓練課表 |

- 第一次使用請先按「🔄 同步 Garmin」把資料抓下來
- 若 Garmin 要求「MFA 驗證碼」，網頁上會跳出輸入框，
  到你的手機 / Email 收驗證碼填入即可
- 資料抓完後，按「🤖 AI 分析」選擇訓練方式與目標賽事，產生課表

## 常見問題

**Q：雙擊 .bat 檔，黑色視窗一閃就不見了？**
A：這些檔案結尾都會「暫停等你按鍵」，正常不會一閃就關。
   若真的閃退，通常是防毒軟體攔截，請允許執行，或尋求協助。

**Q：出現紅色一大串英文錯誤？**
A：請把黑色視窗的內容截圖，連同你做到哪一步一起尋求協助。

**Q：AI 分析失敗、說所有模型都失敗 / 429？**
A：免費 AI 模型有時太多人用會被限流，等幾分鐘再按一次「🤖 AI 分析」即可。

**Q：之後要換 Garmin 密碼或 API Key 怎麼辦？**
A：再雙擊一次「設定帳號.bat」，它會問你要不要覆蓋，重新填入即可。

**Q：每次使用都要重做前面的步驟嗎？**
A：不用。第 1~4 步只需做一次，之後每次只要雙擊「start.bat」就好。
