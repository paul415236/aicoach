# Windows 懶人包（Easy Setup）

這份說明會一步步帶你在 Windows 電腦上使用 Garmin AI Coach。
全部只需要「雙擊」幾個檔案，照著做即可。

> ⚠️ 使用前請務必先閱讀專案 README 開頭的免責聲明。本工具為非官方、個人研究用途，
> 使用第三方函式庫存取 Garmin 帳號資料，可能違反 Garmin 服務條款，風險請自行承擔。

---

## 兩種使用方式，擇一即可

- **方式 A（最簡單，推薦）：免安裝 exe 版** — 不用安裝 Python，下載一個 `AiCoach.exe` 雙擊就能用。請直接看下面的「方式 A」。
- **方式 B：安裝 Python 版** — 需要自己安裝 Python，適合想看原始碼或自行修改的人。請看後面的「方式 B」。

---

## 方式 A：免安裝 exe 版（推薦）

你會拿到兩個檔案（放在**同一個資料夾**）：
- `AiCoach.exe`
- `.env`（設定檔，裡面要填你的帳號與 API Key）

步驟：

1. **準備一組免費的 OpenRouter API Key**
   （這是讓 AI 幫你分析課表用的「鑰匙」，免費，約 2 分鐘）

   1-1. 打開瀏覽器，前往 👉 <https://openrouter.ai/>
   1-2. 點畫面右上角的「**Sign In**」，用 **Google 帳號**登入最快（點 Google 的圖示，選你的 Gmail）
   1-3. 登入後，點右上角你的頭像 → 選單裡點「**Keys**」
         （或直接前往 👉 <https://openrouter.ai/keys>）
   1-4. 點藍色的「**Create Key**」按鈕
   1-5. 名稱隨便打（例如 `aicoach`），其他不用改，按「**Create**」
   1-6. 畫面會顯示一串以 **`sk-or-`** 開頭的長文字 → 點旁邊的「**Copy**」把它複製起來
         ⚠️ 這串只會完整顯示這一次，請先複製好；關掉視窗後就看不到完整內容了

2. **把帳號資料填進 `.env` 設定檔**

   2-1. 找到跟 `AiCoach.exe` 放在一起的 `.env` 檔
   2-2. 對著 `.env` 按**右鍵** →「**開啟方式**」→ 選「**記事本**」
   2-3. 把裡面三行改成你自己的資料（`=` 右邊填你的值，不要留空格）：
        ```
        GARMIN_EMAIL=你的Garmin登入信箱（完整，含 .com）
        GARMIN_PASSWORD=你的Garmin密碼
        OPENROUTER_API_KEY=sk-or-剛剛複製的那串
        ```
   2-4. 按 **Ctrl+S** 存檔，關掉記事本

   > ⚠️ 常見錯誤：信箱要**完整**（例如 `abc@gmail.com`，不要漏掉 `.com`）；
   > `=` 前後不要有空格；三行都要填。

3. **雙擊 `AiCoach.exe`**
   - 會跳出一個黑色視窗，稍等幾秒，瀏覽器會自動開啟 `http://localhost:5000`
   - 第一次執行若出現藍色「**Windows 已保護您的電腦**」視窗，點「**其他資訊**」→「**仍要執行**」即可
     （這是因為此 exe 未經數位簽章，並非病毒）

> ★ 使用期間請**不要關閉那個黑色視窗**，關掉它等於關閉程式。
> 程式會在 exe 同一個資料夾自動建立一個 `data` 資料夾，存放你的跑步資料庫與課表，請勿刪除。

接著就能使用了，操作方式見本文件最後的「開始使用」。

> 💡 給打包者：exe 由專案根目錄的 `aicoach.spec` 產生。在一台裝好 Python 的 Windows 上，
> 雙擊 `windows\build.bat` 即可自動安裝 PyInstaller 並產出 `dist\AiCoach.exe`。

---

## 方式 B：安裝 Python 版

> 以下步驟需要先安裝 Python。若你用的是方式 A（exe 版），可**略過整個方式 B**。

---

## 你需要準備的東西

1. 一台 Windows 10 或 Windows 11 的電腦
2. 你的 **Garmin Connect** 帳號（Email 和密碼）
3. 一組免費的 **OpenRouter API Key**（下面第 2 步會教你拿）

---

## 第 1 步：安裝 Python（只需做一次）

程式需要 Python 才能執行。

1. 打開瀏覽器，前往 👉 <https://www.python.org/downloads/>
2. 點擊黃色的大按鈕「**Download Python**」下載安裝檔
3. 下載完成後，雙擊打開安裝檔
4. **【非常重要】** 安裝畫面最下方，請務必勾選
   ☑️ **「Add Python to PATH」**（加入 PATH）
   ![勾選 Add Python to PATH]
5. 然後點「**Install Now**」，等待安裝完成，最後按「Close」

> 💡 如果你不確定電腦是否已裝過 Python，直接做下面第 3 步也沒關係，
> 若偵測不到會跳出提示叫你回來裝。

---

## 第 2 步：取得免費的 OpenRouter API Key

這是讓 AI 幫你分析課表用的「鑰匙」，免費，約 2 分鐘。

1. 打開瀏覽器，前往 👉 <https://openrouter.ai/>
2. 點右上角「**Sign In**」，用 **Google 帳號**登入最快（點 Google 圖示，選你的 Gmail）
3. 登入後，點右上角頭像 → 選單裡點「**Keys**」（或直接到 👉 <https://openrouter.ai/keys>）
4. 點藍色的「**Create Key**」按鈕
5. 名稱隨便打（例如 `aicoach`），按「**Create**」
6. 複製那串以 **`sk-or-`** 開頭的長文字（點旁邊「**Copy**」）

> ⚠️ 這串只會完整顯示這一次，請先複製好、貼到記事本暫存；關掉視窗後就看不到完整內容。
> 💡 先把它複製著，等一下第 4 步會用到。

---

## 第 3 步：安裝程式依賴套件（只需做一次）

1. 打開程式資料夾裡的 **`windows`** 子資料夾
   （下面要用到的三個 `.bat` 檔都在這個 `windows` 資料夾裡）
2. 找到 **`install.bat`**，**雙擊**它
3. 會跳出一個黑色視窗自動安裝，請耐心等待
4. 看到「**安裝完成！**」字樣後，按任意鍵關閉視窗

> ❓ 如果視窗說「偵測不到 Python」，表示第 1 步沒裝好，
> 請回第 1 步重新安裝，並記得勾選「Add Python to PATH」。

---

## 第 4 步：設定你的帳號（只需做一次）

1. 找到 **`設定帳號.bat`**，**雙擊**它
2. 依照畫面提示，依序輸入：
   - **Garmin Email**：你登入 Garmin Connect 的電子郵件
   - **Garmin 密碼**：你的 Garmin 密碼（輸入時螢幕會顯示，請注意旁邊沒有人）
   - **OpenRouter API Key**：貼上第 2 步複製的那串 `sk-or-...`
     （在黑色視窗中「按右鍵」就能貼上）
3. 看到「**設定完成！**」就好了，按任意鍵關閉

> 🔒 你的帳密只會存在你自己電腦的 `.env` 檔裡，不會上傳到任何地方。

---

## 第 5 步：啟動程式（每次使用都做這步）

1. 找到 **`start.bat`**，**雙擊**它
2. 會跳出黑色視窗，稍等幾秒，瀏覽器會**自動打開**網頁
   （若沒自動開，請自己打開瀏覽器輸入網址：`http://localhost:5000`）
3. 現在就能使用了！

> ★ 使用期間請**不要關閉那個黑色視窗**，關掉它就等於關掉程式。
> 用完後直接關閉黑色視窗即可結束程式。

---

## 開始使用：網頁上的兩個按鈕

| 按鈕 | 作用 |
|---|---|
| 🔄 同步 Garmin | 把最近 12 個月的跑步紀錄從 Garmin Connect 抓下來 |
| 🤖 AI 分析 | 打開設定視窗，產生下週的訓練課表 |

- 第一次使用請先按「🔄 同步 Garmin」把資料抓下來
- 若 Garmin 要求「MFA 驗證碼」，網頁上會跳出輸入框，
  到你的手機 / Email 收驗證碼填入即可
- 資料抓完後，按「🤖 AI 分析」選擇訓練方式與目標賽事，產生課表

## 常見問題

**Q：雙擊 .bat 檔，黑色視窗一閃就不見了？**
A：這些檔案結尾都會「暫停等你按鍵」，正常不會一閃就關。
   若真的閃退，通常是防毒軟體攔截，請允許執行，或尋求協助。

**Q：出現紅色一大串英文錯誤？**
A：請把黑色視窗的內容截圖，連同你做到哪一步一起尋求協助。

**Q：AI 分析失敗、說所有模型都失敗 / 429？**
A：免費 AI 模型有時太多人用會被限流，等幾分鐘再按一次「🤖 AI 分析」即可。

**Q：同步 Garmin 出現「429 Too Many Requests」？**
A：這是 Garmin 伺服器端的限制，短時間登入太多次會被暫時擋。請**等 15～30 分鐘**再試，
   期間不要反覆按同步。

**Q：同步 Garmin 出現「401 Unauthorized」？**
A：帳號或密碼不對。最常見的是**信箱填不完整**（例如漏了 `.com`）。請打開 `.env` 確認
   `GARMIN_EMAIL` 是完整信箱、密碼正確、`=` 前後沒有空格。

**Q：之後要換 Garmin 密碼或 API Key 怎麼辦？**
A：
   - exe 版：用記事本打開 `.env`，改好存檔即可。
   - Python 版：再雙擊一次「設定帳號.bat」，它會問你要不要覆蓋，重新填入即可。

**Q：每次使用都要重做前面的步驟嗎？**
A：不用。第 1~4 步只需做一次，之後每次只要雙擊「start.bat」就好。
